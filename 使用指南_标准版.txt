客户回复排行榜｜标准版使用指南
版本：标准交付包 2026-11-19

一、用途与边界
本工具读取当前 Windows 电脑上、当前登录的微信电脑版 4.x 本地数据库，按互动情况生成客户排行榜和跟进工作台。数据仅保存在本机；网页服务绑定 127.0.0.1（本机），程序不向远端发送聊天数据。打开聊天、复制话术均由使用者确认并手动发送；程序不会自动发送微信消息。

请只在自己有权访问的电脑和微信账号上使用。微信数据库含有个人信息，请按组织的数据处理要求保管电脑、备份及导出文件。不要在共享电脑上运行，不要把生成的 output 目录、wx4_keys.json 或数据库文件发给他人。各地区隐私和数据合规要求不同，使用者需自行确认授权与合规性。

二、系统要求
- Windows 10/11 64 位电脑；微信电脑版 4.x 已安装并登录。
- 首次初始化需要 Python 3.10+ 且已加入 PATH。安装器会检查 Python；缺少时请先安装 Python，并启用“Add Python to PATH”。
- 首次启动会通过 pip 安装 Python 依赖，因此需要可访问 Python 包源的网络。
- 初次解密和扫描通常需要数分钟，视电脑和聊天记录大小而定。

三、首次安装与启动
1. 双击“客户回复排行榜_一键安装.exe”，按提示等待安装完成。无需管理员权限。
2. 安装器会把程序放到当前 Windows 用户的本地程序目录，并在桌面创建“客户回复排行榜”快捷方式。
3. 确认微信电脑版 4.x 已启动并登录，双击桌面快捷方式。首次启动会安装依赖、定位当前微信账号、提取密钥、解密并扫描本机数据。密钥只留在本机。
4. 浏览器会打开本机页面。黑色命令窗口需要保持开启；关闭窗口会停止服务。以后直接双击桌面快捷方式即可刷新数据并启动。
5. 如果扫描结果为空或客户识别不准确，安装目录内双击“设置客户规则.bat”，按提示选择规则，再启动排行榜。

如你拿到的是标准交付 ZIP 而不是安装器，则先解压整个文件夹，再双击“初始化.bat”。

四、日常使用
- 双击桌面“客户回复排行榜”快捷方式会重新读取微信数据、扫描并启动页面；保持微信登录。
- 页面支持搜索、排序、时间筛选、客户标签和跟进状态。点击客户名可查看客户详情、时间线与本地备注。
- “打开聊天”只会切换到微信并搜索/打开联系人。请核对联系人后自行撰写并发送消息。
- 话术模板只用于生成并复制文本，复制后仍需自行检查、粘贴和发送。
- 刷新会重新读取本机微信数据。标签、状态、评分调整、待办、备注及你自行添加的话术存于本目录 config.json。
- 页面显示的榜单是扫描快照；刚发生的互动需刷新/重新扫描后才出现。

五、客户识别规则
“数字开头”适合备注以客户编号开头的联系人；“有备注”会纳入所有有备注联系人；“关键词”按备注中的指定文字筛选。规则仅影响排行榜纳入范围，不会改动微信联系人或聊天内容。初始默认是数字开头。

六、数据与备份
- config.json：本人的标签、状态、评分规则、话术模板、备注和待办。需要迁移人工标注时可单独加密备份此文件；文件不含聊天数据库，但可能包含业务信息。
- output/：扫描结果及生成网页，含聊天摘要等敏感信息，按个人数据对待。
- tools/Moect/wx4_keys.json：微信数据库密钥，严禁分享或上传。
- tools/Moect/app/DataBase/decrypted/：解密后的本地微信数据库，敏感程度最高，严禁分享或上传。
卸载时先退出命令窗口；如需删除本工具数据，请确认备份需求后删除整个工具目录。删除文件不等于安全擦除。

七、常见问题
- 初始化提示找不到微信目录：确认已安装并启动微信 4.x，且当前 Windows 用户登录过微信。
- 密钥提取失败：让微信保持登录并处于运行状态，再运行初始化或排行榜启动脚本；不要把密钥发给他人求助。
- 依赖安装失败：检查网络/代理后重试；必要时用 Python 官方安装程序修复 Python 与 PATH。
- 页面打不开或显示断线：确认“客户回复排行榜.bat”的窗口仍打开，然后在页面点重新连接；若服务已退出，再双击启动脚本。
- 榜单客户不对：使用“设置客户规则.bat”；检查当前登录的电脑微信账号是否正确。
- 打开了同名联系人：微信搜索可能有多个结果，发送前务必在微信中确认联系人身份。
- Windows 安全软件拦截：只从可信来源取得此包；由管理员按组织流程检查源码和依赖，不要为了运行而随意关闭安全防护。

八、包含内容与支持
本标准包包含程序、第三方 wx4 组件及必要脚本，不含原作者交接文档、原作者 config.json、聊天记录、密钥或解密数据库。第三方组件许可和声明见 tools/Moect/LICENSE、THIRD_PARTY_NOTICES.md。该工具依赖微信 4.x 本地数据布局，微信或依赖更新可能导致兼容性变化；若遇到问题，请提供错误文字与系统/微信/Python版本，切勿附上密钥、数据库或聊天记录。
