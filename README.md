# 客户回复排行榜

一个面向 Windows 的微信客户回复分析工具，支持在本地整理聊天记录、统计客户回复情况，并通过内置窗口完成操作。

## 使用方式

1. Windows 电脑安装 Python 3.10 或更高版本。
2. 双击 `初始化.bat` 安装依赖并完成首次设置。
3. 以后双击 `客户回复排行榜.bat` 启动应用。

也可以直接下载 Releases 页面中的 Windows 一键安装包：

<https://github.com/huajuan433/customer-reply-ranking/releases/latest>

## 注意事项

- 数据只在本机处理，不会自动上传聊天内容。
- 首次使用需要按程序提示选择本机数据目录。
- `output/`、数据库、密钥等本地运行数据不会提交到仓库。
