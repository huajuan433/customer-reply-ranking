# 客户回复排行榜 | Customer Reply Ranking

> 面向销售、客服与私域运营的 Windows 本地客户互动分析工具。不上传云端，把本地导出的记录整理成清晰的客户回复排行榜，帮助安排跟进优先级。

客户回复排行榜是一款面向 Windows 的本地客户回复分析工具，帮助销售、客服和运营人员整理**本地导出的聊天记录文件**、统计客户回复情况，并快速找到需要重点跟进的客户。

本项目不注入、不修改聊天客户端，也不读取客户端运行内存；使用前请确认数据来源和使用方式符合所在企业的数据规范。

## 主要功能

- 本地整理客户聊天记录
- 统计客户回复数量和活跃情况
- 生成客户回复排行榜
- 支持客户规则配置
- 内置桌面窗口，减少网页跳转
- 支持 Windows 一键安装
- 数据默认保存在本机

配套工具：[云客跟进助手](https://github.com/huajuan433/yunke-follow-up-assistant) —— 减少 CRM 外呼时在电脑和手机之间反复切换。

## 快速开始

1. Windows 电脑安装 Python 3.10 或更高版本。
2. 双击 `初始化.bat` 安装依赖并完成首次设置。
3. 以后双击 `客户回复排行榜.bat` 启动应用。

## 演示模式（无需读取微信数据）

如果只是想查看界面或制作截图，可以运行：

```powershell
python reply_ranking.py --demo --desktop
```

演示模式使用 18 条完全虚构的客户数据，不读取微信数据库，也不会改动本机聊天数据。

也可以直接下载 Releases 页面中的 Windows 一键安装包：

<https://github.com/huajuan433/customer-reply-ranking/releases/latest>

## 注意事项

- 数据只在本机处理，不会自动上传聊天内容。
- 首次使用需要按程序提示选择本机数据目录。
- `output/`、数据库、密钥等本地运行数据不会提交到仓库。
